# A04 Findings

- "Run tests + retry" alone is **not product-worthy** — trivial plugin, <2 days, already exists implicitly in agents.
- The wedge must be **adaptive verification + evidence/observability** (Pareto: cost/latency/regression/recovery) — this is not provided by incumbents.
- Layered verification (cheap → targeted → regression) is the mechanism that could make the product cost-aware.
- Herdr variant is optional integration, not core — same logic as F03.
- Moat remains thin (<2 weeks) — product competes on evidence quality, not clone difficulty. This is acceptable for PIVOT (extension) but kills standalone.
